# KMITL Schedule Builder

Unofficial browser extension for selecting classes from the KMITL registration teaching table and building a custom timetable.

## Status

Early development.

## Features Planned

- Add checkbox next to each class card
- Select multiple class sections
- Store selected classes locally in the browser
- Generate a weekly timetable view
- Detect conflicting classes
- Clear selected classes
- Export timetable as image or text

## Scope

This extension only modifies the page locally in the user's browser.

It does not:
- collect user data
- access login credentials
- send data to an external server
- bypass access restrictions
- represent itself as an official KMITL product

## Disclaimer

This project is unofficial and not affiliated with KMITL.
